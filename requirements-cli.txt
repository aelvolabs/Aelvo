# AELVO — CLI-only requirements (used by the npm postinstall / launcher).
#
# EVERY version is pinned to the combination this project is tested against.
# Do not loosen these to ranges: an unpinned install is not reproducible and a
# solver-chosen transitive upgrade is exactly how `aelvo` breaks on a user's
# machine while working on the maintainer's.
#
# This is the lean set the terminal agent needs. The heavy web/scraping stack
# (chromadb, scrapy, playwright, watchfiles, selectolax) is NOT here: each is
# imported lazily with a graceful fallback, so the CLI works without them and
# `npm install -g aelvo` stays fast.
#
# Tested interpreter: CPython 3.10 – 3.13 (see bin/lib/python.js).
# Update procedure: see INSTALLATION_ARCHITECTURE.md § "Updating dependencies".
